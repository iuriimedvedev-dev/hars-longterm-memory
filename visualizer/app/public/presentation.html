2 · Pitch 1 · The Retrieval Bottleneck

Why raw grep and naive context fail inside agents

Empirical analysis of 300+ real-world developer queries reveals why traditional search tools fail when handed to autonomous LLMs.

Raw Grep & Basic Context (Status Quo)

  • 84% Miss Rate on Conceptual Queries: Grep fails when the query describes behavior rather than exact literal tokens (e.g. "non-blocking semaphore throttling" implemented via Go channel buffers).
  • Disastrous Token Bloat: Agent cannot locate exact symbol boundaries and repeatedly reads 1,500-line files, blowing past context limits ($0.009+ per turn).
  • Exploration Death Spirals: Misses on initial tool calls cause agents to take 8–15 redundant steps, hallucinating non-existent parameters or giving up.
  • Local Laptop Battery Drain: Local vector DBs (Qdrant, Chroma) and Python cross-encoders eat 12GB+ RAM and cause laptop thermal throttling.

Shared Code-Diver & HARS Memory MCP

  • High-Precision Hybrid Retrieval: Neural embeddings + Tree-sitter AST symbol graphs + BM25 + LightGBM Cross-Encoder Meta-Ranking pinpoint exact functions in milliseconds.
  • Instant Facts Resolution: Pinpoints target snippets in 3.4 to 3.8 steps on average, with 96.5% factual accuracy.
  • -28% to -30% Cheaper Token Burn: Passes tight, bounded symbol excerpts (80 lines) rather than dumping whole source trees into prompt history.
  • Zero Local Infrastructure: 100% hosted on Kubernetes cluster; zero local CPU/memory footprint on developer machines.

8 · Central Architecture & Auto-Reindexing

High-availability Kubernetes architecture on gke-europe-west1

Production deployment verified in namespace iurii-test-space, featuring automatic git synchronization.

Edge Layer
internal-nginx

Technical domain knotgate.labs.jb.gg with TLS certs. Ingresses enforce VPN/office network boundaries.

Gateway & Auth
code-diver-gateway

Port 8080. Verifies Bearer tokens, protects Qdrant paths, routes /code-diver/sse and static artifacts.

Core Engine
code-diver-server

FastAPI + gRPC backend on port 8080/50051. Executes AST extraction, BM25 matching, and LightGBM cross-encoder reranking.

Vector Engine
code-diver-qdrant

Port 6333/6334. High-performance vector storage backed by persistent SSD volumes for sub-10ms similarity queries.

Continuous Repo Monitoring Daemon (hars-sync-daemon)

Auto-Reindexing

Developers never manually trigger index updates. The central daemon monitors repository commits on 60-second intervals:

1. Git Commit Detection

Polls target branches (e.g. master). On new SHA, computes precise file diffs.

2. Incremental HARS Memory Ingest

Modified markdown files in kb/ are parsed, chunked, and upserted into HARS Memory graph and Qdrant collection.

3. Code-Diver Catalog Refresh

Triggers incremental AST symbol graph re-indexing (code-diver index --update-index), keeping symbol spans and dense embeddings fresh.
